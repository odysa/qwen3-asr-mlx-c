# Local ASR compatibility smoke tests

The generic adapter has run one short clip each for the checkpoints below on an Apple M1 Max, Python 3.14.3, MLX 0.32.4 and MLX Audio 0.6.3. The wav2vec2 CTC path is a dedicated adapter in this repository. Revisions are the recorded download targets. For the first seven rows, model files were not hashed at measurement time, so those receipts do not bind their bytes to the revisions. For the four additional rows below, the local model files, inputs and source were hashed before and after the runs and were unchanged. A successful text result indicates that inference returned; it does not prove transcription accuracy, a full language capability, realtime performance, or compatibility of other revisions. The example clips lack independently pinned reference transcripts.

For wav2vec2, text output matched the Hugging Face PyTorch `Wav2Vec2ForCTC` plus processor on the official English example and two English FLEURS clips. The reference loader warned that `wav2vec2.masked_spec_embed` was absent from the checkpoint; this parameter is relevant to training-time masking and the comparison ran in evaluation mode. Three matched outputs are a narrow parity check, not an accuracy evaluation. The two FLEURS samples have their own attribution requirements (see [attribution](quality/ATTRIBUTION.md)).

Checkpoint terms differ: for example, the original [SenseVoiceSmall](https://huggingface.co/FunAudioLLM/SenseVoiceSmall) uses a [custom model license](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE); do not assume it is Apache-2.0. Refer to each exact original and converted model card and dependency license. Other models listed by `list-asr` are upstream modules, not verified checkpoints.

The Nemotron and Canary tests used one English file each, Python 3.14.3, MLX Audio 0.6.3, and whole-file inference via `generate` (no live streaming or timing measured). Their separate local receipt seal SHA-256 is `11f59bd78c178de6d797356f696999b3e676783d0e3d1c1068d226b137727018`. The saved inputs, outputs and options were independently reviewed; no independent inference was run. The [Nemotron MLX conversion card](https://huggingface.co/mlx-community/nemotron-3.5-asr-streaming-0.6b-8bit) declares NVIDIA Open Model License, whereas the current [original NVIDIA model card](https://huggingface.co/nvidia/nemotron-3.5-asr-streaming-0.6b) identifies OpenMDW-1.1. Check the applicable terms for the exact original and conversion rather than assuming all revisions share one license. The Canary checkpoint card declares CC BY 4.0.

The Granite example used a single English file and Python 3.14.3; its local model files, audio and source were hashed before and after and did not change. Receipt seal SHA-256: `9910ecaaf8dbb7f70e3963350553827687efc53cae5baf8968dc8365d92eac1c`. The saved inputs, call and result were independently reviewed without rerunning inference; this does not establish accuracy, speed, streaming or support for other Granite checkpoints.

The VibeVoice checkpoint lacks tokenizer files: the first offline run failed. The subsequent successful example used tokenizer files from [Qwen2.5-7B](https://huggingface.co/Qwen/Qwen2.5-7B), revision `d149729398750b98c0af14eb82c78cfe92750796`, copied into the local model directory before inference. The assembled model directory, audio and source were hashed before and after and did not change. The output's `text` field contained a JSON-serialized segment with speaker and timestamps; the wrapper does not parse or validate these fields, and this is not evidence of diarization or timestamp quality. The local success receipt seal SHA-256 is `007d9c84b96a00c181aa6a81bb9e113b6887d9e58eca6ecfa549749cddc2db3a`; the initial failure is retained separately. The saved input bindings, tokenizer copies and output were independently reviewed without rerunning inference.
